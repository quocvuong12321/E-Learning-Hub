An all-in-one platform for personal branding and online knowledge business.

# 1. Overview

The system integrates:

- A professional blogging platform
- An LMS (Learning Management System) for online courses

Built with Responsive Web Design to ensure smooth performance across:

- Desktop
- Tablet
- Mobile

---

# 2. Goals

- Build a strong personal brand
- Monetize knowledge through online courses
- Provide an effective learning management system

---

# 3. Core Features (MVP)

## Student Features

### Blog

- Category-based articles
- Fast search functionality
- Optimized reading experience

### LMS

- Course library
- Sequential learning flow
- Learning progress tracking
- Quiz after each lesson
- Personal learning dashboard

---

## Admin Features

### CMS

- Create and manage dynamic pages

### Course Builder

- Drag-and-drop course structure
- Embed videos from third-party platforms

### Quiz Management

- Manage questions and pass/fail scores

### Blog Management

- Rich Text Editor
- SEO support

---

# 4. Technical Stack

| Component | Technology |
|---|---|
| Frontend | React.js |
| Backend | Spring Boot |
| Security | Spring Security + JWT |
| Database | MySQL / PostgreSQL |
| Video Hosting | Vimeo Private / YouTube Unlisted |

---

# 5. Roadmap

## Phase 1

- Blog system
- LMS
- Quiz system
- Learning dashboard

## Phase 2

- AI Persona Chatbot
- QR & E-wallet payment integration
